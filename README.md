# Практикум по компьютерной химии и молекулярному моделированию

Скрипты и вспомогательные файлы к учебному пособию.
Код приложен только к лабораторным работам, где используется
программирование; работы в графических пакетах (ChemDraw,
Avogadro без скриптов, HyperChem, GaussView, AutoDock Vina,
WebMO, PyMOL) выполняются по книге и в репозиторий не входят.

## Структура

| Папка | Содержимое |
|-------|------------|
| `Lab_work_4/`  | PubChem и ChEMBL через Python |
| `Lab_work_5/`  | Веб-приложение на Flask + RDKit |
| `Lab_work_6/`  | XYZ-файлы (BeCl₂, BCl₃, CH₄, PF₅, SF₆) |
| `Lab_work_10/` | Конформеры циклогексана (ETKDGv3 + MMFF94) |
| `Lab_work_14/` | Функции Фукуи по выходным файлам Gaussian |
| `Lab_work_22/` | Автоматизация Gaussian (gjf → log → CSV → графики) |
| `Lab_work_26/` | Подготовка данных из ChEMBL |
| `Lab_work_27/` | Расчёт дескрипторов в RDKit |
| `Lab_work_28/` | Построение и применение QSAR-модели |
| `Appendix/`    | Примеры из Приложения 1 |

Работы **№ 26 → 27 → 28** выполняются последовательно:
результат одной — входные данные для следующей.
